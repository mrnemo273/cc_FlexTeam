UX Architecture · Detail 01

The profile takes four shapes.
Each one is named and specified.

One data set. Four expressions. This page wireframes each one so the team can talk about them concretely — instead of saying “the profile” and meaning four different things. Profile is the full page. Card is the browse unit. Bio Module is the tailorable one-page bio (the modern replacement for our bio slide). Pill is the inline credit. They all pull from the same repository.

Lineage — one repository, four expressions
01
EXPRESSION 01 · THE FULL PAGE

Profile

The full profile page. SEO-indexed destination. Cold-inbound landing surface. Pulls every field in the repository, arranged per the Chameleon's archetype default kit. This is “the profile” in the way the team has been talking about it — only now it has a name.

URL pattern
/[name].chameleoncollective.com
or /chameleons/[name]
Pulls from repo
All ~32 fields. Both Chameleon-input and system-derived data.
Variants
One per archetype default kit (4 baseline). Power users customize.
Visual design
See section 10 explorations.
02
EXPRESSION 02 · BROWSE UNIT

Profile · Card

The browse expression. Shown anywhere the system surfaces multiple Chameleons side-by-side — search results, team pages, the who's-available view, the build-a-team assembly flow. Just enough to make a click decision.

Used on
Search results · team pages · who's-available view · build-a-team flow
Pulls from repo
Portrait, name, role, archetype, 3 capabilities, baseball-card stat line, availability badge
Variants
Dense (search) · feature (hero on team page) · build-mode (with select state)
Links to
Profile (full page)
03
EXPRESSION 03 · COMPACT 3-COLUMN · STACKS DENSELY

Profile · Bio Module

A compact, tailored bio designed to stack densely. Desktop: three columns side-by-side. Col 1 — photo + name + title + three core stats (years in industry, total clients in field, location) + action links. Col 2 — tailored headline + short bio. Col 3 — experience card deck, one card at a time (logo, role, tenure, short description), up to five cards. Mobile collapses to a single column with horizontal swipe on the deck. Each module is small enough that ten fit on a practice or team page without overwhelming — wireframe below shows three plus a "+ 7 more" indicator.

Used on
Smart Deliverables (warm pitches) · team-roster sections · practice pages · case study contributors · one-on-one bio sharing
Pulls from repo
Portrait · name · title · LinkedIn URL · tailored headline · short bio · 3 stats (years/clients/location) · up to 5 experience cards (logo + role + tenure + description)
Variants
Desktop 3-column (above) · mobile single-column with swipe deck · PDF export (fallback). Module height ~320px — ten stack cleanly on one practice or team page.
Editable per-pitch
Tailored headline · bio paragraphs · 3 stats (which field/industry context) · experience deck (pick up to 5, set order, write per-pitch descriptions). Identity (name, title, portrait) stays locked. Local override per Idea 33.
04
EXPRESSION 04 · INLINE CREDIT

Profile · Pill

The smallest expression. Inline credit linking back to the Profile. Appears under article bylines, on case-study contributor lines, in body copy when a Chameleon is mentioned in passing. The smallest unit of attribution — and the most embedded.

Used on
Article bylines · case-study contributor lists · inline body copy · podcast credits
Pulls from repo
Name + Profile URL. Optional: avatar, role.
Variants
With-avatar · text-only · with-role (3-field byline)
Auto-generated
When a Chameleon contributes content, the system auto-creates pills wherever they're cited.
What this resolves · what's next

Naming the four expressions ends the “the profile” ambiguity. Going forward: when someone says “the profile,” the team can ask “which expression?” and the answer ties to a real spec. Build order falls out cleanly: Profile and Card are Phase 1 (cold inbound + browse); Bio Module is Phase 1.5 (because Smart Deliverable assembles Bio Modules); Pill is Phase 2 (depends on content repository being live).

Next detail: Smart Deliverable Creator — the warm-pitch live-link surface that assembles 1–3 Bio Modules into a tracked deliverable. Now live.
